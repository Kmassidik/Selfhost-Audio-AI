# docs/ — the public half

**Empty on purpose.**

| | Lives on | Reader | Contains |
|---|---|---|---|
| `knowledge-base/` | the Mac | us | source of truth — measured numbers, **failures included** |
| `docs/` | the box | the public | distilled, self-contained, GitHub-bound |

**Nothing reaches this directory that is not already in the knowledge base.**

The knowledge base is allowed to say *this failed, and here is the prediction we
got wrong*. A published README never does — which is exactly why the two must be
separate files and not one file with a tone problem.

Both siblings arrived at this split independently. See
[`../HOME.md`](../HOME.md) for the full two-machine layout.
