# experiments/ — the lab notebook

Raw findings, before they are good enough to be a chapter.

This is where a result lands the day it happens: the command, the output, what
was expected, what actually occurred. Unpolished on purpose. A finding that has
to be written well before it can be written down does not get written down.

**A file leaves here in one of two ways:**

1. it becomes a chapter in `knowledge-base/`, or
2. it turns out to be wrong — **and it stays, marked wrong, with what replaced it.**

The second is the one that matters. Both siblings keep their disproved
predictions in place and quote them next to the measurement that killed them.
`selfhostllm`'s most-cited finding is a list of seven things that *did not* work.

> *A gap that gets explained is a chapter. A gap that gets ignored is a lie.*
